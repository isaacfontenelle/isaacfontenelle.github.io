PERSONAL PROJECT

Sahra' al-Arwāḥ

Sahra' al-Arwāḥ (loosely, "Desert of Spirits") is a concept art project for a set of enemies designed for a top-down, isometric game in the vein of Hades. Pulling from Arabic folklore and imagery, I set out to design a small cast of otherworldly threats — an undead witch, a ghostly assassin, and a mischievous spirit frog — each built to read clearly at a distance while still holding up in a close-up shot.
