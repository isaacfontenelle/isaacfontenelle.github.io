HOW IT WORKS

  1. 01

    Briefing

    You send references, notes, or a written brief. I ask questions to lock down scope, deadline, and usage before any work starts.

  2. 02

    Sketches

    I send 2–3 rough directions. We pick one (or combine ideas) before moving to refined work.

  3. 03

    Revisions

    A set number of revision rounds are included (see Terms below) so the piece is adjusted before final rendering.

  4. 04

    Delivery

    Final files are delivered in the agreed formats and resolution once payment is complete.

INVESTMENT

Every project is quoted individually — a single character is priced differently from an ongoing visual development contract. Send a brief for an exact quote. Price depends on:

  • Scope — one illustration vs. a full character sheet vs. an ongoing contract.
  • Usage rights — personal use vs. commercial / publishing use.
  • Turnaround — standard timeline vs. a rush request.
  • Revisions — beyond what's included in the base quote.
